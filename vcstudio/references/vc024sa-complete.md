P0107: Введение

P0108: VCSystem представляет собой программный комплекс, предназначенный для создания автоматизированных систем управления. Комплекс состоит из исполняемой среды VCont и среды разработки VCStudio.

P0109: Исполняемая среда VCont – это программно-реализованный контроллер (Soft PLC), который выполняет функции автоматизации различных процессов. Программно-реализованный контроллер или Виртуальный контроллер работает на базе операционной системы реального времени (ОСРВ) семейства Linux, что обеспечивает высокую производительность, детерминированность и надежность выполнения задач управления. Виртуальные контроллеры располагаются на различных вычислительных средствах: промышленных компьютерах, серверах и т.д. Виртуальные контроллеры опционально могут быть настроены для работы в резервированном режиме, чтобы обеспечить отказоустойчивое управление.

P0110: Для конфигурирования системы VCSystem используется среда разработки VCStudio. Среда разработки позволяет сконфигурировать системные настройки контроллера, в том числе, коммуникационные возможности. А также создать логические схемы для управления.

P0111: Для выполнения функций автоматизированной системы программный комплекс работает совместно с модулями ввода/вывода и другими системами сторонних производителей: платформы для сбора, обработки и оперативного управления.

P0112: Данное руководство предназначено для инженеров, разработчиков и специалистов в области автоматизации, которые хотят освоить принципы работы, настройки и программирования Виртуального контроллера. В нем рассмотрены основные концепции, архитектура и ограничения Виртуального контроллера.

P0288: Создание Задач

P0289: Контур управления состоит из функциональных блоков, которые определяют алгоритм для обработки данных.

P0290: Функциональный блок может обрабатываться двумя способами:

P0291: в событийной задаче через событие, которое подаётся на событийный вход;

P0292: в периодической задаче через его запуск в порядке циклической очереди. Каждый контур должен быть назначен задаче.

P0293: Таким образом, существуют следующие типы задач:

P0294: периодические (функциональные блоки выполняются один раз в заданный период);

P0295: событийные (блоки выполняются от триггеров событий).

P0296: Для создания задачи необходимо ЛКМ два раза нажать на ресурс (см. Рисунок 36). Откроется окно редактирования ресурса. Необходимо выбрать вкладку «Задачи». Во вкладке можно редактировать существующие задачи или создавать новые.

P0297: Новая задача создается при нажатии ЛКМ на значок  ресурс.

P0298: Возможна смена имени задачи. Для этого, необходимо нажать ЛКМ два раза на задачу. При этом, она выделяется синим цветом (см. Рисунок 37).

P0350: Изменение типа данных ANY портов функциональных блоков

P0351: Некоторые функциональные блоки имеют порты с типом данных ANY, ANY_BIT, ANY_MAGNITUDE и т. д. (далее – ANY-типы).

P0352: Увидеть такие порты можно, если нажать ЛКМ на порт функционального блока или просто навести курсор, Рисунок 50.

P0353: Рисунок 50 – Пример ФБ ADD с портом ANY_MAGNITUDE

P0354: Порты с ANY-типом данных по умолчанию оперируют типами REAL (например, арифметические (Arithmetic) –ADD, DIV и др.), BOOL (например, логические (Logic) – AND, OR и др.) и т. п.

P0355: На рисунке 51 на первый вход блока AND поступает тип данных BYTE, но т.к. этот ФБ по умолчанию оперирует с типами данных BOOL, то он преобразует входящее значение в TRUE, так как оно больше нуля. На второй вход блока AND поступает тип данных BOOL, что соответствует «родному» типу данных.

P0356: Таким образом к подобного рода портам можно подключать порты любого разрешённого типа.

P0357: Конечно, если попытаться подключить порт REAL к порту ANY_BIT, то ничего не выйдет, так как ФБ с портами ANY_BIT выполняет операции только с битовыми переменными

P0358: Рисунок 51 – Пример работы ФБ AND с ANY-типом данных в случае соединений разными типами портов

P0359: Чтобы изменить тип данных, которыми порты ANY-типа оперируют по умолчанию, необходимо (см. Рисунок 52):

P0483: Создание алгоритмов с помощью языка ST

P0484: Инструменты студии позволяют создавать функциональные блоки и контура на языке ST, которые также могут быть использованы совместно с блоками из базовой библиотеки функциональных блоков.

P0485: В основе работы студии лежит механизм трансляции кода Structured Text (ST) в исполняемый Lua-код.

P0486: Это позволяет:

P0487: Использовать высокопроизводительные библиотеки Lua.

P0488: Обеспечить кросс-платформенность.

P0489: Применять отладчики и профайлеры Lua к коду ST.

P0490: При описании алгоритма на языке ST можно использовать стандартные функции: арифметические (ADD, DIV, MOD, SUB и т.д.), битовые (ROL, SHR, AND, OR и т.д.), строковые (CONCAT, DELETE, FIND и т.д.) и функции преобразования типов (BOOL_TO_BYTE, REAL_TO_INT и т.д.)

P0491: Общие сведения о языке ST

P0492: ST (Structured Text) — язык высокого уровня с универсальным применением, синтаксически близкий к Pascal. Он хорошо подходит для задач, связанных с численным анализом и нетривиальными вычислительными алгоритмами.

P0493: В соответствии со стандартом IEC 61131-3, ключевые конструкции языка следует записывать заглавными буквами. Форматирование (пробелы и табуляция) не влияет на синтаксис и может применяться свободно.

P0494: Синтаксис выражений полностью повторяет Pascal:

P0495: [переменная] := [значение];

P0496: Вычисления выполняются справа налево. Выражения строятся из операндов и операторов. В качестве операнда могут выступать: явно заданное значение (литерал), переменная (в т.ч. структурная), компонент сложной переменной, результат вызова функции или прямой адрес.

P0497: При записи арифметических выражений допустимо использование скобок для указания порядка вычислений.

P0498: Символ «(* *)» используется для многострочного комментария.

P0499: (*Многострочный комментарий*)

P0500: Разработчику доступен следующий функционал:

P0501: Арифметические операции:

P0502: «+» – сложение;

P0503: «-» – вычитание;

P0504: «*» – умножение;

P0505: «/» – деление;

P0506: «mod» – остаток от целочисленного деления.

P0507: Логические операции:

P0508: «OR» – Логическое (побитовое) сложение;

P0509: «AND» – Логическое (побитовое) умножение;

P0510: «XOR» – Логическое (побитовое) «исключающее ИЛИ»;

P0511: «NOT» – Логическое (побитовое) отрицание.

P0512: Операции сравнения:

P0513: «=» – сравнение на равенство;

P0514: «<>» – сравнение на неравенство;

P0515: «>» – сравнение на больше;

P0516: «>=» – сравнение на не меньше;

P0517: «<» – сравнение на меньше;

P0518: «<=» – сравнение на не больше.

P0519: В качестве результата сравнения всегда используется значение типа BOOL.

P0522: цикл FOR;

P0524: цикл REPAET UNTIL;

P0525: конструкция CASE.

P0526: Типы данных:

P0527: Спецификация IEC 61131-3 определяет для ST полный набор типов, типичный для распространённых языков программирования.

P0528: Целые типы (со знаком и без):

P0529: SINT (аналог char), USINT (unsigned char)

P0530: INT (short int), UINT (unsigned int)

P0531: DINT (long), UDINT (unsigned long)

P0532: LINT (64-битное целое), ULINT (64-битное целое без знака)

P0533: Вещественные типы:

P0534: REAL (float)

P0535: LREAL (double)

P0536: Битовые строки фиксированной длины:

P0537: BYTE, WORD, DWORD, LWORD — 8, 16, 32 и 64 бита соответственно.

P0538: В ST нет битовых полей как отдельных сущностей, но доступ к отдельным битам возможен напрямую. Пример:

P0539: a.3 := 1; % (* Третий бит переменной a устанавливается в 1 *)

P0540: Логический тип BOOL принимает значения TRUE или FALSE и физически часто реализуется на уровне одного бита.

P0541: Строковый тип STRING представляет собой именно последовательность символов (а не массив). Для строк поддерживаются стандартные операции сравнения и копирования, например:

P0542: strA := strB; %(Содержимое strB копируется в strА)

P0543: Расширенная работа со строками обеспечивается встроенными функциями, см пункт ****

P0544: Специализированные (Временны’е) типы по стандарту IEC:

P0545: TIME — для интервалов длительности,

P0546: TOD — для времени суток,

P0547: DATE — для календарной даты,

P0548: DT — для комбинированного момента времени (дата + время).

P0549: По умолчанию, все переменные инициализируются нулем. Иное значение переменной можно указать явно при ее объявлении. Например:

P0550: str1: STRING := ‘Hello world’;

P0551: В определённых ситуациях при разработке программных модулей удобно использовать обобщения типов, т.е. общее именование группы типов данных. Например тип ANY – объединяет все доступные типы.

P0567: Управляющие операторы

P0568: При описании алгоритмов на языке ST можно использовать операторы выбора (IF ELSE, CASE) и операторы цикла (FOR, WHILE, REPEAT). Разрешается использовать также вложенные операторы. По умолчанию спецификация IEC 61131-3 предусматривает символ «;» в конце операторов (END_CASE;  END_IF; и т.д.) однако современные трансляторы и студии позволяют опускать этот символ.

P0569: При описании конструкций языка были использованы фигурные и квадратные скобки. Считается, что:

P0570: выражение в фигурных скобках < > может использоваться ноль или больше раз подряд;

P0571: выражение в квадратных скобках [ ] не обязательно к использованию.

P0572: CASE

P0573: Данная конструкция служит для организации выбора из диапазона значений. Формат конструкции следующий:

P0574: CASE <Переменная> OF

P0575: <Список значений>:

P0576: <Выражение>

P0577: [ELSE <Выражение>]

P0578: END_CASE

P0579: <Переменная> - целочисленная локальная переменная объявляемая в коде ФБ. Обычно это тип данных INT или в некоторых случаях – ENUM.

P0580: <Список значений> — это конкретные значения, которые принимает <Переменная>. Значения могут перечисляться через запятую, а для указания диапазона значений можно использовать следующую запись <Начальное значение>..<Конечное значение>.

P0581: Если текущее значение <Переменной> не попало ни в один <Список значений>, то управление будет передано ELSE. Если ключевое слово ELSE не указано, то никаких действий выполнено не будет.

P0582: VAR_INPUT

P0583: STATE_NUM:INT;

P0584: END_VAR

P0585: VAR_OUTPUT

P0586: MESS:STRING;

P0587: END_VAR

P0588: CASE STATE_NUM OF

P0589: 1:

P0590: MESS:='ONE';

P0591: 2..5 :

P0592: MESS:='TWO-FIVE';

P0593: 6,7,8:

P0594: MESS:='SIX-EIGHT';

P0595: ELSE

P0596: MESS:='UNREAL_STATE';

P0597: END_CASE

P0598: IF IFLSE

P0599: Данная конструкция служит для организации выбора в зависимости от истинности условия.

P0600: Конструкция IF-ELSEIF-ELSE имеет следующий формат:

P0601: IF <Условие > THEN <Выражение>

P0602: [ELSEIF <Условие> THEN <Выражение >]

P0603: [ELSE < Выражение >]

P0604: END_IF;

P0605: <Условие> - выражение, обычно записываемое с использованием логических операторов сравнения. Результат этого выражения всегда обязан являться булевым значением (TRUE, FALSE). В случае, если <Условие> является булевой переменной, то использование логических операторов сравнения необязательно.

P0606: Если <Условие> - истина, то выполняется <Выражение>, в противном случае управление переходит ELSEIF (если присутствует это ключевое слово). Проверка последующих ELSEIF условий происходит строго последовательно. Если ни одно из условий не является истинным, управление переходит ELSE. Если ключевое слово ELSE не указано, то никаких действий выполнено не будет.

P0609: END_VAR

P0610: VAR_OUTPUT

P0611: MESS:STRING;

P0612: END_VAR

P0615: MESS:='SEVEN';

P0616: ELSIF IN_VAL>10 AND  15 >=  IN_VAL THEN

P0625: FOR

P0626: Служит для задания цикла с фиксированным количеством итераций. Формат конструкции следующий:

P0627: FOR <Итератор>:= <Выражение1> TO <Выражение2>

P0628: [BY <Выражение3>] DO

P0629: <Выражение>

P0630: END_FOR;

P0631: <Итератор> - обычно, локальная INT переменная. Увеличивается с каждым выполнением тела цикла на <Выражение3>.

P0632: <Выражение1>, <Выражение2>, <Выражение3> при задании условий цикла предполагается, что имеют тип INT. <Выражение1> - стартовое значение цикла. <Выражение2> - конечное значение цикла. <Выражение3> - шаг итерации.

P0633: Выход из цикла будет произведен в том случае, если значение <Итератора> цикла превысит значение <Выражение2>. Таким образом, если границы цикла, например, были указаны некорректно (от 7 до 4 с шагом 1), то цикл не выполнится не разу. Если необходимо производить итерацию в обратном порядке, тогда <Выражение3> должно быть отрицательным. Для досрочного завершения цикла используется оператор EXIT.

P0634: Если [BY <Выражение3>] не указано, то предполагается, что шаг равен «1».

P0635: VAR_INPUT

P0636: N:INT;

P0637: END_VAR

P0638: VAR_OUTPUT

P0639: COUNT:INT:=0;

P0640: END_VAR

P0641: VAR

P0642: I:INT;

P0643: END_VAR

P0644: FOR I:= 1 TO N/2 BY 1 DO

P0645: COUNT:=COUNT+2;

P0646: END_FOR;

P0647: WHILE

P0648: Служит для определения цикла с предусловием. Цикл будет исполняться до тех пор, пока выражение в предложении WHILE возвращает TRUE Формат конструкции следующий:

P0649: WHILE <Условие> DO

P0650: <Выражение>

P0651: END_WHILE;

P0652: <Условие> - результат всегда булевое значение, проверяется на каждой итерации. Завершение цикла произойдет, если <Условие> вернет FALSE.

P0653: Внутри цикла могут использоваться другие циклы, операторы IF и CASE. Для досрочного завершения цикла используется оператор EXIT.

P0654: При использовании WHILE следует учитывать, что, попадая в этот цикл, контроллер как бы «зависает» до выполнения <Условия>. В это время не проверяются значения входов ФБ, а значит контроллер может пропустить аварийную ситуацию. Типичное использование: при инициализации контроллера или, например, для поиска символа в строке.

P0655: VAR_INPUT

P0656: IN_STRING:STRING;  (*Входная символьная строка*)

P0657: FIND_SYMBOL:STRING;  (*Искомый символ или группа символов*)

P0658: END_VAR

P0659: VAR

P0660: i:INT; (*Итератор*)

P0661: END_VAR

P0662: VAR_OUTPUT

P0663: POS:INT; (*Позиция искомого символа в строке, 0-если в строке нет символа*)

P0664: STR_LEN:INT; (*Всего символов в строке*)

P0665: END_VAR

P0666: STR_LEN:=LEN(IN_STRING);

P0667: WHILE (STR_LEN >= i) AND (POS = 0) DO

P0668: IF IN_STRING[i] = FIND_SYMBOL THEN

P0669: POS := i;

P0670: END_IF;

P0671: i:=i+1;

P0672: END_WHILE;

P0673: REPEAT

P0674: Служит для определения цикла с постусловием. Завершение цикла произойдет тогда, когда выражение в предложении UNTIL вернет FALSE. Другими словами: цикл будет выполняться, пока условие в предложении UNTIL не выполнятся. Формат конструкции следующий:

P0675: REPEAT

P0676: <Выражение>

P0677: UNTIL <Условие>;

P0678: END_REPEAT;

P0679: <Условие> - результат всегда булевое значение, проверяется на каждой итерации. Завершение цикла произойдет, если <Условие> вернет TRUE.

P0680: Внутри цикла могут использоваться другие циклы, операторы IF и CASE. Для досрочного завершения цикла используется оператор EXIT.

P0681: Для цикла REPEAT справедливо всё то, что отмечалось для цикла WHILE. Их единственное отличие заключается в том, что цикл REPEAT выполнится гарантированно хотя бы один раз, в отличие от WHILE, который может ни разу не выполнится.

P0682: VAR_INPUT

P0683: IN_STRING:STRING; (*Входная символьная строка*)

P0684: FIND_SYMBOL:STRING; (*Искомый символ или группа символов*)

P0685: END_VAR

P0686: VAR

P0687: i:INT; (*Итератор*)

P0688: END_VAR

P0689: VAR_OUTPUT

P0690: POS:INT; (*Позиция искомого символа в строке, 0-если в строке нет символа*)

P0691: STR_LEN:INT; (*Всего символов в строке*)

P0692: END_VAR

P0693: STR_LEN:=LEN(IN_STRING);

P0694: REPEAT

P0695: IF IN_STRING[i] = FIND_SYMBOL THEN

P0696: POS := i;

P0697: END_IF;

P0698: i:=i+1;

P0699: UNTIL i > STR_LEN OR POS > 0

P0701: Массивы

P0702: В языке ST массивы являются фундаментальным инструментом для работы с группами однородных данных.

P0703: Массивы объявляются с использованием ключевых слов ARRAY, OF и указания границ индексов

P0704: VAR

P0705: Имя_массива : ARRAY [нижняя_граница .. верхняя_граница] OF тип_данных;

P0706: END_VAR

P0707: Инициализация массивов происходит похожим образом, как и для обычных переменных. Инициализированные элементы массива записываются в квадратных скобках, через запятую. Неинициализированные элементы получат значение по умолчанию (ноль для чисел, FALSE для BOOL, пустая строка для STRING). Никакой ошибки компиляции или выполнения не будет. Также доступно использование многомерных массивов.

P0708: VAR

P0709: (* Одномерный массив с явным перечислением *)

P0710: arr : ARRAY [-2..2] OF INT:= [1, 2, 3, 4]; (*arr[-2]=1, arr[-1]=2, arr[0]=3, arr[1]=4, arr[2]=0 *)

P0711: (* Двумерный массив 2×3, все элементы = 25 *)

P0712: matrix1 : ARRAY [1..2, 1..3] OF INT := [2([3(25)])];

P0713: (*  Двумерный массив с явным перечислением *)

P0714: matrix2 : ARRAY [1..2, 1..3] OF INT := [[11, 12, 13], [21, 22, 23]];

P0715: END_VAR

P0716: Использование безразмерных массивов на ST не предусмотрено, это обусловлено тем, что для ПЛК важно предсказуемое время выполнения, а это возможно только при фиксированном выделении памяти.

P0717: Тем не менее, допускается возможность использования константных переменных в качестве границ массива

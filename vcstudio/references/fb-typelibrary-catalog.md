репозитория VCStudio. Исходные `Comment` и `Identification` значения сохранены

## Source Shape

- Распарсено `.fbt` файлов: `473`.
- Корень XML: `FBType`. Практически полезный интерфейс лежит в `InterfaceList`.
- Событийные порты показаны как `EVENT[WITH_VAR,...]`, когда `.fbt`
  объявляет `With`-связи.
- Data-порты показаны как `NAME:TYPE`; повторяющиеся номерные порты сжаты в
  диапазоны, например `WD01..WD50:ANY`.
- `InterfaceOnly` означает, что в этом snapshot видна только декларация
  интерфейса; runtime-реализация может жить в VCont или generated code.

## How To Use

- Для генерации bootfile используй `IN` и `OUT` как допустимые имена/типы pins
  для `WRITE`, `READ` и `CREATE Connection`.
- Для event-driven блоков сохраняй связь event/data, показанную в `EI` и `EO`
  через списки `With`.
- Для диагностики и тестов бери output pins из этого каталога, а не угадывай
  имена. Runtime-значения проверяй на текущих бинарях VCont, если важна
  фактическая семантика.
- Device blocks вроде `EIPDEV`, `KNXDEV` и Modbus device rows могут иметь
  конфигурацию преимущественно в runtime `Options`, даже если их `.fbt`
  interface пустой.

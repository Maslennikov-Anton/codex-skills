# Доказательства покрытия

Verdict относится к покрытию тестом, не к реализации продукта:

| Verdict | Основание |
| --- | --- |
| covered | Исполнимый путь и oracle проверяют все условия требования на нужном объекте/входе. |
| partial | Часть условий проверена, остальные перечислены явно. |
| contradicted | Assertion требует поведение, противоречащее нормативному контракту. |
| absent | В проверенной области не найден сценарий/ожидание после поиска по ID, действию, helpers и вызывающим тестам. |
| undecidable | Не хватает документа, разрешения неоднозначности, динамического binding или другого существенного evidence. |

Для каждой строки сохраняй ссылку на версию документа и строку/страницу, путь и строки сценария и assertion, предусловия, ограничения. Coverage matrix — указатель для поиска, а не итоговое доказательство. Если один сценарий включает несколько требований, проверяй каждый oracle отдельно.

Пример: «viewer не редактирует объект, состояние сохраняется». Проверка лишь disabled-кнопки — partial: не проверены альтернативный путь изменения и неизменность состояния, если они входят в контракт. Отсутствие runtime evidence не превращает статическое covered в доказанный pass продукта.

При отрицательном результате перечисли просмотренные вероятные места. Если scope не включает весь набор тестов, пиши «не найдено в scope», а не «тестов нет».
